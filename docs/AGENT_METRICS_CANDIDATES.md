# 主对话链路需要计算的指标清单

## 成长能力
- 营收同比增长率
- 归母净利润同比增长率
- 扣非净利润同比增长率
- 营收环比增长率
- 净利润环比增长率
- 多年复合增长率（CAGR）
- 经营性现金流同比

## 盈利能力
- 毛利率
- 净利率
- ROE
- ROA
- 销售费用率
- 管理费用率
- 财务费用率

## 偿债能力/流动性
- 资产负债率
- 流动比率
- 速动比率
- 有息负债率

## 运营效率
- 存货周转天数
- 应收账款周转天数
- 总资产周转率

## 现金流质量
- 净利润现金含量
- 自由现金流
- 收现比

## 估值
- 市盈率（PE）
- 市净率（PB）
- 市销率（PS）
- 股息率
- PEG

## 行情与资金面
- 区间涨跌幅
- 区间资金净流入
- 换手率均值
- 区间振幅

## 预告/预期偏离
- 业绩预告同比区间
- 业绩快报同比
- 预告与实际偏离度

## 组合/相对表现
- 相对指数超额收益
- 多标的指标排名
